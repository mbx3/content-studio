# استودیو محتوا

اپ شخصی برای تولید و تحلیل محتوای اینستاگرام: بانک ایده، خط تولید (سناریو، کپشن، منابع، چک‌لیست)، تقویم محتوایی، ثبت آمار سر موعد، تحلیل، قیف بیمار، دفترچه‌ی درس‌ها و بانک هوک و CTA.

**داده‌ها فقط روی گوشی خودت ذخیره می‌شن.** این ریپو فقط کد اپ رو داره و هیچ پست، آمار یا اطلاعات بیماری داخلش نمی‌ره؛ برای همین Public بودنش مشکلی نداره.

---

## راه‌اندازی روی گیت‌هاب (حدود ۱۰ دقیقه)

### ۱. ساخت ریپو
1. وارد [github.com](https://github.com) شو (اگه اکانت نداری، Sign up).
2. بالای صفحه روی **+** و بعد **New repository** بزن.
3. **Repository name** رو بنویس: `content-studio`
4. گزینه‌ی **Public** رو انتخاب کن. (گیت‌هاب پیجز برای اکانت رایگان فقط روی ریپوی Public کار می‌کنه.)
5. تیک **Add a README file** رو **نزن**؛ خود این فایل README هست.
6. **Create repository** رو بزن.

### ۲. آپلود فایل‌ها
1. فایل `content-studio.zip` رو باز کن (Extract). داخلش ۹ فایله.
2. توی صفحه‌ی ریپوی تازه، روی لینک **uploading an existing file** بزن.
   (یا از **Add file** ← **Upload files**.)
3. **هر ۹ فایل** رو با هم انتخاب کن و بکش داخل صفحه. خود پوشه رو آپلود نکن؛ فایل‌ها باید مستقیم توی صفحه‌ی اول ریپو باشن.
4. پایین صفحه **Commit changes** رو بزن.

روی گوشی هم می‌شه: سایت گیت‌هاب رو توی کروم باز کن، **Add file** ← **Upload files** و از پوشه‌ی دانلود، هر ۹ فایل رو با هم انتخاب کن.

### ۳. روشن کردن GitHub Pages
1. توی ریپو برو به **Settings** و از منوی کنار، **Pages**.
2. زیر **Build and deployment**، قسمت **Source** رو روی **Deploy from a branch** بذار.
3. **Branch** رو `main` و پوشه رو `/ (root)` انتخاب کن و **Save** بزن.
4. یکی دو دقیقه صبر کن و صفحه رو رفرش کن. بالای همین صفحه آدرس اپ میاد:
   `https://نام-کاربری.github.io/content-studio/`

### ۴. نصب روی گوشی
1. آدرس بالا رو توی **کروم** گوشی باز کن.
2. از منوی سه‌نقطه‌ی کروم، **نصب برنامه** (Install app) یا **افزودن به صفحه‌ی اصلی** رو بزن. اگه اپ خودش دکمه‌ی «نصب اپ» نشون داد، همون رو بزن.
3. از این به بعد از آیکون روی صفحه‌ی اصلی بازش کن. تمام‌صفحه باز می‌شه و بعد از اولین باز شدن، بدون اینترنت هم کار می‌کنه.

با نگه‌داشتن انگشت روی آیکون، میان‌برهای «ایده‌ی جدید»، «ثبت آمار» و «دایرکت یا نوبت» هم میاد.

### ۵. وارد کردن اطلاعات اولیه
فایل `studio-start-data.json` (جدا از این ریپو فرستاده شده) پست‌ها، آمارها، ایده‌های در حال تولید و درس‌های تا امروزت رو داره.
توی اپ روی **وارد کردن فایل** بزن و همین فایل رو انتخاب کن.

این فایل رو **توی ریپو آپلود نکن**؛ ریپو عمومیه.

## پشتیبان‌گیری

چون داده‌ها فقط روی گوشی‌ان، اگه اپ یا داده‌های کروم پاک بشه یا گوشی عوض بشه، فقط با فایل پشتیبان برمی‌گردن.

- هفته‌ای یک بار: **بیشتر** ← **پشتیبان‌گیری** ← **فرستادن به تلگرام یا درایو** (بهترین جا: Saved Messages تلگرام).
- برای برگرداندن یا بردن به گوشی دیگه: همون‌جا **وارد کردن از فایل**.
- اپ هر هفته روی صفحه‌ی خانه یادت می‌اندازه (از تنظیمات قابل تغییره).

## به‌روزرسانی اپ در آینده

هر وقت نسخه‌ی تازه‌ای از فایل‌ها گرفتی (مثلاً از Claude):
1. توی ریپو **Add file** ← **Upload files** و فایل‌های جدید رو با همون اسم‌ها آپلود کن؛ جایگزین قبلی‌ها می‌شن.
2. چند دقیقه بعد، وقتی اپ رو باز کنی، بالای صفحه «نسخه‌ی جدید اپ آماده‌ست» میاد. **به‌روزرسانی** رو بزن. داده‌هات دست نمی‌خورن.

اگه خودت چیزی رو توی کد عوض کردی، عدد `VERSION` اول فایل `sw.js` رو هم عوض کن، وگرنه گوشی نسخه‌ی قبلی رو نگه می‌داره.

## فایل‌ها

| فایل | کارش |
|---|---|
| `index.html` | صفحه‌ی اصلی اپ |
| `app.js` | همه‌ی منطق اپ |
| `styles.css` | ظاهر و رنگ‌ها |
| `sw.js` | نگه‌داشتن اپ روی گوشی برای حالت آفلاین و به‌روزرسانی |
| `manifest.webmanifest` | اسم، آیکون و تنظیمات نصب |
| `icon-192.png`، `icon-512.png`، `icon-maskable.png` | آیکون‌ها |
| `README.md` | همین راهنما |

## اگه مشکلی پیش اومد

- **صفحه‌ی 404:** چند دقیقه صبر کن. اگه درست نشد، چک کن فایل‌ها مستقیم توی صفحه‌ی اول ریپو باشن (نه داخل یک پوشه) و Pages روی `main` و `/ (root)` تنظیم شده باشه.
- **گزینه‌ی نصب نمیاد:** آدرس رو حتماً توی کروم باز کن و مطمئن شو با `https://` شروع می‌شه.
- **github.io باز نمی‌شه:** بعضی وقت‌ها روی بعضی اینترنت‌ها کند یا قطعه. اپِ نصب‌شده بدون اینترنت هم کار می‌کنه؛ فقط برای نصب اول و گرفتن نسخه‌ی جدید لازمه سایت باز بشه.
- **فونت با بقیه‌ی جاها فرق داره:** فونت وزیرمتن بار اول از اینترنت گرفته می‌شه. اگه در دسترس نباشه، اپ با فونت خود گوشی کار می‌کنه.
- **داده‌ها پرید:** از آخرین فایل پشتیبان، **وارد کردن از فایل** بزن. اگه بعد از یک واردکردن یا پاک کردن اشتباه بود، **برگرداندن نسخه‌ی قبلی** هم توی همون صفحه هست.
