# استودیو محتوا

اپ شخصی برای تولید و تحلیل محتوای اینستاگرام: بانک ایده، خط تولید (سناریو، کپشن، منابع، چک‌لیست)، تقویم محتوایی، ثبت آمار سر موعد، تحلیل، قیف بیمار، دفترچه‌ی درس‌ها، بانک هوک و CTA، پشتیبان خودکار، تحلیل با Claude و دریافت خودکار آمار اینستاگرام.

**این ریپو فقط کد اپ رو داره** و هیچ پست، آمار یا اطلاعات بیماری داخلش نیست؛ برای همین Public بودنش مشکلی نداره. داده‌ها روی گوشی و (با روشن کردن پشتیبان خودکار) توی ریپوی **خصوصی** `studio-data` نگه داشته می‌شن.

---

## راه‌اندازی روی گیت‌هاب (حدود ۱۰ دقیقه)

### ۱. ساخت ریپو
1. وارد [github.com](https://github.com) شو (اگه اکانت نداری، Sign up).
2. بالای صفحه روی **+** و بعد **New repository** بزن.
3. **Repository name** رو بنویس: `content-studio`
4. گزینه‌ی **Public** رو انتخاب کن. (گیت‌هاب پیجز برای اکانت رایگان فقط روی ریپوی Public کار می‌کنه.)
5. تیک **Add a README file** رو **نزن**؛ خود این فایل README هست.
6. **Create repository** رو بزن.

### ۲. آپلود فایل‌ها
1. فایل `content-studio.zip` رو باز کن (Extract). داخلش ۹ فایله.
2. توی صفحه‌ی ریپوی تازه، روی لینک **uploading an existing file** بزن.
   (یا از **Add file** ← **Upload files**.)
3. **هر ۹ فایل** رو با هم انتخاب کن و بکش داخل صفحه. خود پوشه رو آپلود نکن؛ فایل‌ها باید مستقیم توی صفحه‌ی اول ریپو باشن.
4. پایین صفحه **Commit changes** رو بزن.

روی گوشی هم می‌شه: سایت گیت‌هاب رو توی کروم باز کن، **Add file** ← **Upload files** و از پوشه‌ی دانلود، هر ۹ فایل رو با هم انتخاب کن.

### ۳. روشن کردن GitHub Pages
1. توی ریپو برو به **Settings** و از منوی کنار، **Pages**.
2. زیر **Build and deployment**، قسمت **Source** رو روی **Deploy from a branch** بذار.
3. **Branch** رو `main` و پوشه رو `/ (root)` انتخاب کن و **Save** بزن.
4. یکی دو دقیقه صبر کن و صفحه رو رفرش کن. بالای همین صفحه آدرس اپ میاد:
   `https://نام-کاربری.github.io/content-studio/`

### ۴. نصب روی گوشی
1. آدرس بالا رو توی **کروم** گوشی باز کن.
2. از منوی سه‌نقطه‌ی کروم، **نصب برنامه** (Install app) یا **افزودن به صفحه‌ی اصلی** رو بزن. اگه اپ خودش دکمه‌ی «نصب اپ» نشون داد، همون رو بزن.
3. از این به بعد از آیکون روی صفحه‌ی اصلی بازش کن. تمام‌صفحه باز می‌شه و بعد از اولین باز شدن، بدون اینترنت هم کار می‌کنه.

با نگه‌داشتن انگشت روی آیکون، میان‌برهای «ایده‌ی جدید»، «ثبت آمار» و «دایرکت یا نوبت» هم میاد.

### ۵. وارد کردن اطلاعات اولیه
فایل `studio-start-data.json` (جدا از این ریپو فرستاده شده) پست‌ها، آمارها، ایده‌های در حال تولید و درس‌های تا امروزت رو داره.
توی اپ روی **وارد کردن فایل** بزن و همین فایل رو انتخاب کن.

این فایل رو **توی ریپو آپلود نکن**؛ ریپو عمومیه.

---

## ثبت پست‌های قدیمی

- **پستی که توی اپ نیست:** دکمه‌ی + ← «پست منتشرشده». عنوان، تاریخ، سری و برچسب‌ها توی یک صفحه‌ان و بعدش مستقیم فرم آمار باز می‌شه.
- **پستی که توی اپ هست ولی تاریخ نداره:** محتوا ← منتشرشده ← «بدون تاریخ». روی هر کارت دکمه‌ی «ثبت تاریخ انتشار» هست.
- **ساعت انتشار اختیاریه.** اگه نمی‌دونی، «نامعلوم» بمونه. همه‌ی تحلیل‌ها به‌جز «ساعت انتشار» فقط با روز کار می‌کنن.
- **تاریخ میلادی:** اینستاگرام تاریخ رو میلادی نشون می‌ده؛ تقویم اپ زیر هر روز شمسی، روز میلادی رو هم ریز نوشته.

## پشتیبان خودکار

**بیشتر** ← **پشتیبان و همگام‌سازی** ← **روشن کردن پشتیبان خودکار**. سه قدم داره و هر کدوم یک دکمه:
1. ساخت ریپوی خصوصی `studio-data` (حتماً **Private**).
2. ساخت توکن دسترسی: دسترسی‌ها از قبل انتخاب شده‌ان؛ فقط **Only select repositories** و بعد `studio-data` رو انتخاب کن و **Generate token** رو بزن.
3. توکن رو توی اپ بچسبون و **اتصال** رو بزن.

بعدش اپ بعد از هر تغییر یک نسخه توی گیت‌هاب ذخیره می‌کنه و تاریخچه‌ی همه‌ی نسخه‌ها می‌مونه. **کد بازیابی** رو توی Saved Messages تلگرام نگه دار: اگه اپ پاک یا ریست شد یا گوشی رو عوض کردی، روی صفحه‌ی اول اپ **بازگردانی از گیت‌هاب** رو بزن و همین کد رو بچسبون.

اپ رو همیشه از آیکون روی صفحه‌ی اصلی باز کن. هر مرورگری (کروم، مرورگر سامسونگ، مرورگر داخل تلگرام) حافظه‌ی جدای خودش رو داره و داده‌های یکی رو اون یکی نمی‌بینه.

پشتیبان فایلی هم هنوز هست: همون صفحه ← **فرستادن به تلگرام یا درایو**.

## تحلیل با Claude

**بیشتر** ← **تحلیل‌های Claude**. سؤالت رو ثبت کن (یا «درخواست تحلیل کامل» رو بزن)؛ اپ یک پیام آماده کپی می‌کنه که توی چت Claude می‌فرستی. Claude داده‌ها رو از `studio-data` می‌خونه و تحلیل و پیشنهادهاش رو همون‌جا می‌نویسه؛ توی اپ **بروزرسانی** رو بزن و هر پیشنهاد رو با **اعمال** به درس‌ها، ایده‌ها، پست‌ها یا آمارها اضافه کن.

برای اینکه Claude به ریپو دسترسی داشته باشه، اپ Claude باید روی گیت‌هابت نصب باشه: github.com/apps/claude ← Install ← **Only select repositories** ← `content-studio` و `studio-data`.

## آمار خودکار اینستاگرام

**بیشتر** ← **اینستاگرام** ← **راهنما و تنظیمات**. بعد از راه‌اندازی، گیت‌هاب هر ۳ ساعت آمار پست‌ها رو از API رسمی اینستاگرام می‌گیره: تاریخ و ساعت دقیق انتشار، ویو، ریچ، لایک، کامنت، شیر، سیو، واچ‌تایم و اسکیپ‌ریت؛ برای پست‌های عادی و کاروسل‌ها، فالوور جدید و بازدید پروفایل هم. فالوور جدید از هر ریلز رو اینستاگرام از این راه نمی‌ده.

راه‌اندازی به یک اپ توسعه‌دهنده در Meta نیاز داره (developers.facebook.com، با حساب فیسبوک و VPN). متا ایران رو رسماً پشتیبانی نمی‌کنه و ممکنه حساب توسعه‌دهنده رو محدود کنه. قبل از ساختن توکن، مجوز `instagram_business_manage_insights` رو به اپ متا اضافه کن؛ بدونش فقط فهرست پست‌ها میاد و اپ همین رو بهت می‌گه.

پست‌هایی رو که از قبل توی اپ داری، با «وصل به…» به پست اینستاگرامیشون وصل کن تا تکراری نشن، یا از Claude بخواه جفتشون کنه؛ پیشنهادهاش با «اعمال» وصل می‌شن.

## به‌روزرسانی اپ در آینده

هر وقت نسخه‌ی تازه‌ای از فایل‌ها گرفتی (مثلاً از Claude):
1. توی ریپو **Add file** ← **Upload files** و فایل‌های جدید رو با همون اسم‌ها آپلود کن؛ جایگزین قبلی‌ها می‌شن.
2. چند دقیقه بعد، وقتی اپ رو باز کنی، بالای صفحه «نسخه‌ی جدید اپ آماده‌ست» میاد. **به‌روزرسانی** رو بزن. داده‌هات دست نمی‌خورن.

اگه خودت چیزی رو توی کد عوض کردی، عدد `VERSION` اول فایل `sw.js` رو هم عوض کن، وگرنه گوشی نسخه‌ی قبلی رو نگه می‌داره.

## فایل‌ها

| فایل | کارش |
|---|---|
| `index.html` | صفحه‌ی اصلی اپ |
| `app.js` | همه‌ی منطق اپ |
| `styles.css` | ظاهر و رنگ‌ها |
| `sw.js` | نگه‌داشتن اپ روی گوشی برای حالت آفلاین و به‌روزرسانی |
| `manifest.webmanifest` | اسم، آیکون و تنظیمات نصب |
| `icon-192.png`، `icon-512.png`، `icon-maskable.png` | آیکون‌ها |
| `README.md` | همین راهنما |

## اگه مشکلی پیش اومد

- **صفحه‌ی 404:** چند دقیقه صبر کن. اگه درست نشد، چک کن فایل‌ها مستقیم توی صفحه‌ی اول ریپو باشن (نه داخل یک پوشه) و Pages روی `main` و `/ (root)` تنظیم شده باشه.
- **گزینه‌ی نصب نمیاد:** آدرس رو حتماً توی کروم باز کن و مطمئن شو با `https://` شروع می‌شه.
- **github.io باز نمی‌شه:** بعضی وقت‌ها روی بعضی اینترنت‌ها کند یا قطعه. اپِ نصب‌شده بدون اینترنت هم کار می‌کنه؛ فقط برای نصب اول و گرفتن نسخه‌ی جدید لازمه سایت باز بشه.
- **فونت با بقیه‌ی جاها فرق داره:** فونت وزیرمتن بار اول از اینترنت گرفته می‌شه. اگه در دسترس نباشه، اپ با فونت خود گوشی کار می‌کنه.
- **داده‌ها پرید:** با کد بازیابی **بازگردانی از گیت‌هاب** بزن، یا از آخرین فایل پشتیبان **وارد کردن از فایل**. نسخه‌های قبلی هم توی **تاریخچه‌ی نسخه‌ها** هست.
- **پشتیبان خودکار خطا می‌ده:** اگه پیام درباره‌ی توکنه، یک توکن تازه بساز و از همون صفحه دوباره وصل کن. اگه درباره‌ی اینترنته، چند دقیقه بعد خودش دوباره امتحان می‌کنه.
